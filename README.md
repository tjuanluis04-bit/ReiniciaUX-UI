# Reinicio UI

App Android (Kotlin + Jetpack Compose) que reinicia SystemUI y/o el launcher usando Shizuku, con widget para la pantalla de inicio.

## Compilar con GitHub Actions
1. Crea un repositorio y sube todo el contenido de esta carpeta (incluida `.github/`).
2. Ve a la pestaña **Actions** › **Compilar APK** (se ejecuta solo al hacer push a `main`, o con *Run workflow*).
3. Al terminar, descarga el APK desde **Artifacts** › `Reinicio-UI-APK`.

## Uso
1. Inicia Shizuku e instala el APK.
2. Abre la app y toca **Conceder permiso**.
3. Toca el botón central o añade el widget.
